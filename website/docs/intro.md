# Платформа для создания персонализированных образовательных материалов с элементами академической социальной сети

ИС позволяет генерировать курсы, статьи и другие образовательные материалы с помощью LLM. Контент формируется с учётом указанных пользователем сложности, тематики и структуры. Источники: открытые курсы Stepik, статьи Medium, личные материалы пользователя. Реализована публикация сгенерированного контента на персональной странице, его чтение, рецензирование и распространение — элементы академической соцсети.

- **MVP:** генерация черновика курса, загрузка материалов, базовый редактор, публикация, рецензирование, поиск, аналитика, пополнение баланса.
- **Целевая аудитория:** студенты, молодые специалисты, преподаватели, корпоративные заказчики, эксперты.
