## UC-1 — Генерация черновика
| ID | Категория | Требование | Приоритет | Обоснование |
|---|---|---|---|---|
| NFR-UC1-01 | Security | mTLS между backend и LLM API | MUST | Защита ПДн в прикреплённых материалах |
| NFR-UC1-02 | Privacy | Шифрование черновиков AES-256, помеченных «приватно» | MUST | Соответствие ФЗ-152, требования корпоративных клиентов |
| NFR-UC1-03 | Operational | Лимит 20 бесплатных генераций в месяц на автора | MUST | Бюджет API LLM (при 3000 пользователей и 25% MAU — 15 000 генераций, ~1800 USD/мес) |
| NFR-UC1-04 | Performance | Подтверждение приёма запроса ≤ p95 2 сек | SHOULD | UX асинхронных операций |
| NFR-UC1-05 | Performance | Время генерации черновика ≤ p95 120 сек | SHOULD | Данные по RAG-моделям: простые запросы ~2-5 сек, сложные до 60-90 сек |
| NFR-UC1-06 | Reliability | Доступность сервиса генерации ≥ 99.5% в месяц | MUST | Допустимое downtime ≤ 3.6 ч/мес, компромисс стоимость/риск для MVP |

## UC-2 — Загрузка материалов
| ID | Категория | Требование | Приоритет | Обоснование |
|---|---|---|---|---|
| NFR-UC2-01 | Security | Загрузка только для аутентифицированных | MUST | Защита от злоупотреблений, юридическая ответственность |
| NFR-UC2-02 | Capacity | Максимальный размер файла 20 МБ | MUST | Ограничение облака 10 ТБ в MVP (300 ГБ на 3000 пользователей) |
| NFR-UC2-03 | Compatibility | Приём только .txt/.md и .pdf | MUST | Снижение стоимости хранения, упрощение RAG |

## UC-5 — Поиск и запись
| ID | Категория | Требование | Приоритет | Обоснование |
|---|---|---|---|---|
| NFR-UC5-01 | Performance | Задержка поиска ≤ p95 500 мс при 100 RPS | MUST | Ориентир веб-поиска; замеры на OpenEdu: медиана 270 мс, p95 ≤ 410 мс |
| NFR-UC5-02 | Scalability | Кеширование популярных запросов TTL 5 мин | SHOULD | Снижение нагрузки в пики |
| NFR-UC5-03 | Performance | Топ-5 результатов содержат ≥80% релевантных курсов для семантических запросов | COULD | Бизнес-цель, но полноценное векторное решение за рамками MVP |
