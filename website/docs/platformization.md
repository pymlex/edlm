## Вынос на публичную платформу
Витрина курсов, доступ к обучению, оплата, подписка, сертификаты, прогресс, пространства для компаний — передаются на Open edX. Внутри остаются генерация черновика, версионирование, редактор, публикация, проверка, история изменений.

## Интеграция с Open edX
- Авторский контур — своя система.
- После публикации структура курса, метаданные, материалы отправляются в Open edX через REST API.
- Запись пользователя — Enrollment API (`add_enrollment`).
- Аутентификация: JWT (OAuth2 client credentials).

## Аналог Stepik
- Платформа для РФ, курсы, корпоративный контур.
- API: REST JSON, OAuth2, pagination.
- Монетизация: базовая бесплатно, платные курсы с комиссией (40% при продвижении, 7% с авторской ссылки), enterprise по запросу.

## Стратегия монетизации
- B2B2C: подписка для компаний/вузов, дополнительно — внедрение, миграция, кастомизация.
- Версионирование: MVP — базовая публикация; v2 — пространства компаний; v3 — глубокая аналитика и адаптивные траектории.
