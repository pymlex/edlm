## C1. System Context

```plantuml
@startuml
top to bottom direction
skinparam nodesep 100
skinparam ranksep 100
skinparam shadowing false
skinparam packageStyle rectangle

actor "Студент" as student
actor "Автор" as author
actor "Администратор" as admin

rectangle "EDLM" as edlm
rectangle "Open edX" as openedx
rectangle "Notification Service" as ns
rectangle "RabbitMQ" as mq

student --> edlm : ищет курсы
author --> edlm : "редактирует\nчерновики"
admin --> edlm : модерация

edlm --> openedx : "публикация\nкурсов"
edlm --> mq : "события жизненного\nцикла"
mq --> ns : уведомления

@enduml
````
