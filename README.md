# EdLM

EdLM — платформа для создания персонализированных образовательных материалов с элементами академической социальной сети.

## Структура репозитория

- `website/` — сайт на Docusaurus
- `.github/workflows/` — автодеплой на GitHub Pages

## Запуск локально

```powershell
cd website
npm install
npm run start
```
